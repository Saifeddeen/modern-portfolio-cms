Portfolio CMS
A full-stack Portfolio CMS built with Laravel 13, Vue 3 (Composition API), Inertia.js, Tailwind CSS, and PrimeVue.

Tech Stack
- Backend: Laravel 13, REST API
- Frontend: Vue 3, Inertia.js, Vite
- UI: Tailwind CSS, PrimeVue, Lucide Icons
- Media: Spatie Laravel Media Library

Setup
1. composer install
2. npm install
3. cp .env.example .env
4. php artisan key:generate
5. php artisan migrate
6. `npm run dev
